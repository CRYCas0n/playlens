# ADR-021 — Проверять окружение, а не предполагать его отсутствие

**Статус:** принято · 2026-09-06
**Связанные:** ADR-018 (портируемость БД), ADR-019 (модель угроз)

## Context

Первая редакция `FINAL_AUDIT.md` содержала раздел «что НЕ проверено» из шести пунктов.
Три из них были обоснованы фактом: PostgreSQL не установился (диск), Docker-демона нет,
ключей LLM и YouTube нет.

Три других были обоснованы **предположением**:

* «вёрстка на 390/768/1024/1440 — в браузере эти страницы не открывались»;
* «SSE по проводу — ASGI-транспорт не умеет прерывать бесконечный генератор»;
* «image-прокси по сети — фактическая загрузка не проверена».

Первое и третье оказались неверны. Chromium был установлен на машине всё это время
(`ms-playwright/chromium-1234`, плюс системный Chrome), Node доступен, сеть работает —
`metacritic.com` отвечает 200. Второе было верно про *конкретный* транспорт, но неверно
как вывод: настоящий uvicorn на настоящем сокете тестируется тривиально.

Проверка занимала три команды: `ls`, `node --version`, `curl -o /dev/null -w "%{http_code}"`.

Цена предположения оказалась высокой. Браузер и сеть нашли **пять дефектов**, которые
700 автоматических тестов не видели:

1. каждая KPI-плитка дашборда печатала целиком служебный объект;
2. каждая страница ехала вбок на 390px;
3. image-прокси получал 403 на каждом запросе (User-Agent);
4. `/favicon.ico` давал 404 и console error на каждой странице;
5. `.env.example` расходился с `Settings`.

## Decision

**`NOT VERIFIED` пишется только после попытки проверить, и запись называет, что именно
было проверено и чем.**

Практически:

1. Прежде чем объявить проверку невозможной — выполнить команду, которая это установит.
   Отсутствие инструмента доказывается запуском инструмента, а не памятью о том, что его
   обычно нет.
2. Если инструмент есть в системе, но не в проекте — использовать системный. Браузерный
   проход гоняется через уже установленный Chrome и уже закэшированный npm-пакет
   Playwright; проект не приобрёл ни одной Node-зависимости.
3. Причина в `NOT VERIFIED` формулируется проверяемо. «Нет Docker-демона» проверяемо.
   «В браузере не открывалось» — описание бездействия, а не препятствия.

## Что теперь проверяется по-настоящему

| Проверка | Чем | Что нашла |
|---|---|---|
| Вёрстка | `scripts/browser_smoke.mjs`: Chromium, 12 страниц × 4 ширины, измерение переполнения и console errors | 3 дефекта |
| SSE | `tests/integration/test_sse_wire.py`: uvicorn в потоке, httpx по сокету | формат кадров и реплей подтверждены |
| Живой источник | `tests/contract/`: реальные запросы, opt-in по `CONTRACT_TESTS=1` | форма ответа и правило «10 на страницу» подтверждены |
| Image-прокси | реальная обложка, скачивание + ресайз + кэш | дефект User-Agent |
| N+1 | счётчик statement-ов на 30 играх | N+1 нет |
| Downgrade миграций | отдельная БД, upgrade → base → upgrade | откат работает |

## Alternatives considered

| Вариант | Почему не выбран |
|---|---|
| Оставить как было и честно пометить | Пометка была честной по намерению и ложной по факту: три пункта из шести были проверяемы |
| Ставить Playwright и Chromium в проект | На диске 149 МБ. Chromium — 150. Системный браузер решает ту же задачу бесплатно |
| Добавить Node-зависимости в репозиторий | Проект не имеет Node-части. Один `.mjs`-скрипт, который находит Playwright там, где он уже есть, не создаёт `package.json` и не тянет `node_modules` |
| Считать браузерные тесты не нужными при 700 unit-тестах | Ровно эти 700 тестов проходили, пока дашборд печатал служебный объект в каждую плитку. Проверка присутствия строки на странице не видит того, что там ещё есть |

## Consequences

* Три новых вида проверок, ни одна не обязательна для `make test`: браузер требует
  запущенного сервера, contract-набор требует `CONTRACT_TESTS=1`.
* `PROJECT_STATUS.md` различает `BLOCKED` (машина не позволяет, с конкретной причиной) и
  `IMPLEMENTED — NOT VERIFIED` (проверять нечем прямо сейчас).
* Осталось три `BLOCKED`, и у каждого причина, которую можно перепроверить одной
  командой: свободное место на диске, наличие `docker`, наличие ключа.

## Risks

| Риск | Митигация |
|---|---|
| Браузерный проход зависит от версии установленного Chrome | Скрипт пробует `CHROME_PATH`, затем канал `chrome`, затем `msedge`, затем собственный Chromium Playwright, и печатает внятную ошибку, если ничего нет |
| Contract-набор бьёт по чужому серверу | Двойной opt-in: маркер `contract` **и** `CONTRACT_TESTS=1`. Внутри — 1 запрос в секунду, вдвое медленнее продового дефолта |
| Кто-то примет `--dry-run` прогон Release 0 за измерение | Скрипт печатает предупреждение и пишет `dry_run: true` в отчёт |
