# Открытые вопросы

**Дата:** 2026-09-06 · вторая редакция после финального прохода

Разделено по тому, что вопрос **блокирует**. Разработка не останавливается из-за вопросов,
которые можно безопасно закрыть разумным инженерным решением: такие закрыты, решение
зафиксировано в ADR, а вопрос переведён в non-blocking с указанием принятого дефолта.

---

## A. Blocking — без ответа корректная реализация невозможна

| # | Вопрос | Почему блокирует | Что уже сделано, чтобы не стоять |
|---|---|---|---|
| **OQ-B1** | **Файла исходного ТЗ в репозитории нет.** Требования восстановлены по матрице соответствия `BLUEPRINT.md §27` (35 пунктов) и по тексту задания | Traceability строится по реконструкции. Если в оригинале есть пункт, не отражённый в §27, он не попадёт в матрицу | `REQUIREMENTS_TRACEABILITY.md` построена по реконструкции и помечена как таковая. **Просьба: положить исходный файл ТЗ в `docs/ASSIGNMENT.md`** — матрица будет пересверена за один проход |
| **OQ-B2** | **Ключ YouTube Data API отсутствует.** Без него Bonus 1 нельзя ни запустить, ни измерить | Реальное покрытие транскриптами неизвестно; квота не проверена | Код Bonus 1 написан и покрыт тестами на фикстурах. `YOUTUBE_ENABLED=false` по умолчанию. Включение — ключ + одна переменная (ADR-016) |
| **OQ-B3** | **Правовой режим эксплуатации.** Внутренняя демонстрация или публичный доступ? Коммерческое использование? | ToS Fandom запрещает автоматизированный сбор; `backend.metacritic.com` — неофициальный интерфейс. От ответа зависит, можно ли выкладывать сервис наружу | Принят режим «учебный/тестовый, внутренняя демонстрация»: дисклеймер в README, `/about` и футере; консервативный rate limit; `HtmlSource` готов; scrape YouTube выключен (ADR-001, ADR-019). **Публичный запуск требует явного решения владельца** |
| **OQ-B4** | **Ключ Anthropic API отсутствует.** AI-конвейер не выполнялся на живой модели | Цифры Release 0 получены в интерактивном режиме и объявлены **потолком**; production-качество не измерено | `LLM_ENABLED=false` по умолчанию; в тестах — детерминированный `FixtureLLMProvider`, воспроизводящий формат и граничные случаи. Весь конвейер (снапшот → промпт → валидация → хранение) проверен end-to-end без сети |

## B. Validation — требуют целевого окружения, не блокируют разработку

## C. Non-blocking — закрыты инженерным решением, открыты для пересмотра

| # | Вопрос | Принятый дефолт | Основание | Когда пересмотреть |
|---|---|---|---|---|

| **OQ-N2** | Пороги: `SIMILARITY_MIN_SCORE=0.34`, `AGREEMENT_THRESHOLD=7`, `GAP_MIN_POINTS=7`, `PLATFORM_GAP_MIN_POINTS=10` | Значения из дизайна (7) и подобранные (0.34, 10) | 7 — из `design/prototype/assets/app.js`, нормативно. 0.34 подобран так, чтобы у игр с seed-каталогом было 4–6 похожих | После калибровки на реальном каталоге ≥5000 игр |
| **OQ-N3** ✅ закрыт частично | Браузерные E2E | **Сделано**: `scripts/browser_smoke.mjs` гоняет настоящий Chromium по 12 страницам на 4 ширинах и проверяет горизонтальное переполнение, console errors, статусы, тему и фильтры. | **OQ-N4** | Модель LLM по умолчанию | `claude-sonnet-5` | Компромисс цены и качества; смена — одна переменная. `BLUEPRINT §28 Q3` оценивал ~$1.5–4/сутки на Opus | После OQ-V3 |
| **OQ-N5** | Кэпы отзывов: 200 critic / 500 user на пару (игра, платформа) | Приняты | `BLUEPRINT §28 Q6`; выборка стратифицирована, для суммаризации репрезентативна; лента отзывов пользователю не показывается | При появлении фичи «свежие vs старые отзывы» |
| **OQ-N6** | Глубина каталога | Игры с Metascore (18 524) | ADR-015; полный обход 177 882 — ~370 суток при лимите ТЗ | При решении о долгом backfill |
